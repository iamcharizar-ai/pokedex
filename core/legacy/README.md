# core/legacy: the rules as they were on the last day before version 22

Frozen on 12 Nov 2026 (GAME-SPEC-V22.md, section 12.1). **Never edit these files.** They fold every day before `V22_START`, so a day already lived is always replayed under the rules it was lived under. A fix to old behaviour belongs in a new version, not here.

Everything shared with the new rules (`facts.ts`, `events.ts`, `order.ts`, `day.ts`, `strong.ts`, `species.ts`, `gyms.ts`, `types.ts`) stays one level up.
